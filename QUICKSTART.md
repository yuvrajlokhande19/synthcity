# SynthCity — Quick Start

SynthCity is a civic intelligence and crisis-response prototype that brings together incident information, geospatial views, AI-assisted workflows, citizen communication examples, and optional sensor telemetry.

## Try the Demo

**Live demo:** https://yuvrajlokhande19.github.io/synthcity/

**Demo video:** https://youtu.be/rWri_K3XDis

## Demo Walkthrough

1. Open the live demo.
2. Explore the dashboard and available map views.
3. Open an available incident or simulation to see the response workflow.
4. Review the AI-agent workflow and the roles of the six agents.
5. Explore the Telegram communication examples.
6. If hardware is connected, demonstrate the ESP32 + HC-SR04 sensor reading.

## Hardware

The demonstration setup uses an ESP32 development board and an HC-SR04 ultrasonic distance sensor.

- Verify wiring and voltage compatibility before powering the circuit.
- Calibrate readings against a known distance.
- Treat sensor readings as experimental telemetry, not certified flood warnings.

## Important Notes

Some views or workflows may use sample data, simulation, or fallback behavior. Confirm which integrations are live before presenting them as real-time services. SynthCity is a prototype and should not be relied upon for real emergency decisions.
