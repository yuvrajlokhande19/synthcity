📡 ESP-01 ULTRASONIC FLOOD SENSOR HARDWARE SETUP

Hardware Requirements:

    ESP8266 ESP-01 Microcontroller Module HC-SR04 Ultrasonic Distance Sensor 3.3V Power Supply / Regulator Jumper Wires & Breadboard

Wiring Connections:

ESP-01 GPIO0 --> HC-SR04 TRIG ESP-01 GPIO2 --> HC-SR04 ECHO ESP-01 VCC --> 3.3V Power ESP-01 CH_PD --> 3.3V Power ESP-01 GND --> Common Ground

Arduino C++ Code Snippet (`esp01_flood_sensor.ino`):

#include <ESP8266WiFi.h>
#include <ESP8266HTTPClient.h>

const char* ssid = "YOUR_WIFI_SSID";
const char* password = "YOUR_WIFI_PASSWORD";
const char* firebaseUrl = "https://my-project-1-602b7-default-rtdb.firebaseio.com/telemetry/esp01_flood.json";

const int TRIG_PIN = 0; // GPIO0
const int ECHO_PIN = 2; // GPIO2

void setup() {
  Serial.begin(115200);
  pinMode(TRIG_PIN, OUTPUT);
  pinMode(ECHO_PIN, INPUT);
  WiFi.begin(ssid, password);
}

void loop() {
  digitalWrite(TRIG_PIN, LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG_PIN, HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG_PIN, LOW);
  long duration = pulseIn(ECHO_PIN, HIGH);
  float distanceCm = duration * 0.0343 / 2.0;

  // Send payload to SynthCity Firebase
  delay(5000);
}
